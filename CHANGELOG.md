# Changelog

Все заметные изменения в этом проекте будут задокументированы в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
и этот проект следует [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

---

## [1.0.0] - 2024-01-15

### Добавлено

#### Backend (Django)
- ✅ CRM модуль с управлением местами, сессиями, бронированиями
- ✅ Система лояльности с реферальной программой
- ✅ Управление тарифами и акциями
- ✅ REST API для всех операций
- ✅ Django Admin панель
- ✅ Тесты моделей и представлений

#### Telegram Bot
- ✅ Базовый бот с командами /start, /status, /me
- ✅ Интеграция с Django API
- ✅ Docker поддержка

#### Web Dashboard
- ✅ Операционный дашборд
- ✅ Супер-дашборд с аналитикой
- ✅ Управление тарифами и акциями
- ✅ Список клиентов с поиском

#### Инфраструктура
- ✅ Docker Compose для всех сервисов
- ✅ GitHub Actions для CI/CD
- ✅ Pre-commit hooks
- ✅ Линтеры (flake8, eslint)
- ✅ Форматирование (black, prettier)
- ✅ Документация API
- ✅ Руководство по развёртыванию

### Технологии

| Компонент | Технологии |
|-----------|------------|
| Backend | Django 5.2, DRF, SQLite |
| Bot | Node.js, node-telegram-bot-api |
| Dashboard | HTML, CSS, JavaScript |
| CI/CD | GitHub Actions |
| Качество | pytest, flake8, eslint, prettier |
